### Task 1: Reconcile `expo-build-properties` to the SDK-54 version + clear `expo-doctor`

**Why:** `package.json` pins `expo-build-properties` at `^56.0.15` — an SDK-56-aligned major on an SDK-54 project — and it is **actively used** (it supplies the Android `minSdkVersion: 26 / compileSdkVersion: 35 / targetSdkVersion: 35` config in `app.json`'s `plugins`). A wrong-SDK config plugin can silently mis-generate the Android build — exactly the kind of failure the single build can't absorb. This task pins it to the version Expo expects for SDK 54 and confirms there are no other SDK mismatches, **without** disturbing the deliberately-pinned `expo-speech-recognition@3.1.3`.

**Files:**

- [ ] **Step 2: Pin `expo-build-properties` to the reported version**

Small correctness fix; low risk; worth landing in the single build so the toggle behaves.

**Files:**
- Modify: `app/home.tsx`

- [ ] **Step 1: Confirm `useCallback` + `useFocusEffect` are available**

